# Changelog

All notable releases of Zaoly are documented here.

## 0.1.1 — 2026-10-22

Public pack refresh.

- Baked Zaoly seal favicon (browser tabs show the logo reliably)
- Email logo CDN via public `aurovylabs/zaoly-delivery` (jsDelivr)
- Landing / product polish since `0.1.0`
- Prebuilt image: `ghcr.io/aurovylabs/zaoly-delivery:0.1.1` (also `:latest` from this tag)

## 0.1.0 — 2026-10-11

First public open-source release.

- Editor-first enterprise web design surface (`/editor`)
- Site Kit atoms, masters/variants, Token Studio, Kit Playground
- Local develop (`npm run dev`) and Docker self-host Compose
- Prebuilt image: `ghcr.io/aurovylabs/zaoly-delivery:0.1.0`
- AGPL-3.0-only
