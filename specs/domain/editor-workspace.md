### Layers panel IA (E6 / E7 + P20/P21)

- One tree rooted at the **active page** root (P80) or Master-edit working root; row = node `name` or `type` + id meta.
- Click row → same selection as canvas (`select` UI state; P19: modifiers for multi).
- Expand/collapse containers with `children`; session-only collapse OK for stub.
- **Reorder / nest:** `LayersPanel` `onMoveUp` / `onMoveDown` → `reorder_node` among siblings. **P20:** drag-reorder via DS `onReorderDrop` → same op for sibling before/after. **P76 nest:** drop `into` a container (or before/after a row under another parent) → `move_node` (reparent). Reject: root, locked, cycle (into descendant), non-container into. **Alt+]** nests primary selection into the previous sibling container; **Alt+[** unnests (after parent among grandparents).
- **P21 Hide/lock:** eye + padlock via `LayersPanel` `onToggleHidden` / `onToggleLocked`. Persist `SceneNode.hidden` / `SceneNode.locked` (contracts). Hidden nodes not painted / not hit-tested; locked reject mutating ops (ancestor cascade).
- Do **not** invent a second project model — tree is the composition scene only.
