## Do and Don't

### Do

- Use the documented props and sizes (`md` default — square magazine chrome).
- Keep copy on type roles / tokens — no ad-hoc rem weights.
- Prefer `<Button>` or `buttonClassName()` on links — not hand-rolled `.ds-btn--*` strings.

### Don't

- Do not invent one-off styles outside the design-system CSS layers.
- Do not call live APIs from Storybook stories.

## Accessibility

Prefer roles, labels, and keyboard paths already used in product UI.

## Tokens consumed

DS-DEPOSIT D5 — variants consume Brandion paths via Layer 0 CSS vars. Enums stay React API (no `button.variant.ghost` leaves).

See `knowledge/ds-deposit-component-semantic-map.md`.

| Variant | CSS | Brandion path |
|---------|-----|---------------|
| primary | `--accent` | `color.action.primary` (background) |
| ghost | `--muted` / `--line` | `color.muted` / `color.line` |
| subtle | mix `--ink` | `color.ink` |
| danger | `--danger` | `color.status.danger` |
| link | `--accent` | `color.action.primary` (color) |

Primary foreground `#1a150c` is hardcoded (not a token leaf). Sizes use `--type-sm` / `--space-*`; pill `--radius-pill`.
