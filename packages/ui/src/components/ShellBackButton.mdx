# ShellBackButton

Fixed **top-left** history-back plaque — mirror of `BrandCorner`.

Spec: `specs/domain/zaoly-ui-shell-back-button.md`

## Usage

Pass `onClick` from the app (`router.back()`). Optional `href` renders an anchor.

Mount via `AppFrame` `backCorner` so the decorative TL shell scoop is omitted.
