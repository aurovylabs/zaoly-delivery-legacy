## Do and Don't

### Do

- Use the documented props and sizes (`sm` default for controls).
- Keep copy on type roles / tokens — no ad-hoc rem weights.

### Don't

- Do not invent one-off styles outside the design-system CSS layers.
- Do not call live APIs from Storybook stories.

## Accessibility

Prefer roles, labels, and keyboard paths already used in product UI.
