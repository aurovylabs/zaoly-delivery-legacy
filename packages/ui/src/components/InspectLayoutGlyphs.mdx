# Inspect Layout Glyphs

Layer: `Foundation`

Theme-aware SVG diagrams for inspect chrome: size modes (Hug / Fill / Fixed), media fit (Cover / Contain / …), and grid column / span presets.

Fills use `--ink` (readable on light and dark). Accents use `--accent`. Frames use `--line`. Do not hardcode `#fff` or brand hex in consumers.

Spec: `specs/domain/zaoly-ui-inspect-layout-glyphs.md`
