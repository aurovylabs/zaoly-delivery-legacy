## Do and Don't

### Do

- Provide `getRowId` and stable column `id`s.
- Use `sortValue` only on columns that should sort.

### Don't

- Do not pull TanStack/virtualization until product needs it.
- Do not nest interactive controls without clear labels.

## Accessibility

Sortable headers expose `aria-sort`. Prefer caption for table purpose.
