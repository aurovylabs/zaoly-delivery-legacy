# ChatOverlay

Layer: `Organisms`

Domain-free chat flyout / overlay shell (`dock-end` | `center`). Body is a slot for a **composed** compact chat panel or a product iframe (Plexon `/assistant/embed`).

Token surfaces (`--panel` / `--bg1`, `--line`, `--ink`, `--overlay-scrim`) follow host `data-theme` — use the Storybook theme toolbar to verify light/dark.

## Dock end (primary)

Side sheet `min(32rem, 100%)` — classical assistant flyout.

## Do

- Mount from product AppShell hosts (`PlatformAssistantHost`).
- Keep assistant/domain message logic out of this package.

## Don't

- Put a second page title / expand chrome inside the body when the overlay header already owns them.
- Hardcode light/dark colors on the sheet.
