# CollectionHubCard

**Spec:** `specs/domain/zaoly-ui-collection-hub-card.md`  
**Origin:** Brandion project tiles (CHECKION / PLEXON clones)

## Stories

- Default / Pending / Create

/>

<CollectionHubCard variant="create" title="New project" hint="…" onClick={open} />
