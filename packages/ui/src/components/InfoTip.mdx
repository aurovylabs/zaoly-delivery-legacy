# InfoTip

Layer: `molecules`

Ghost `IconInfo` button + hover/focus `Tooltip` for short metric/jargon help.

Spec: `specs/domain/zaoly-ui-infotip.md`

## Props

- `content` — tip body (`ReactNode`)
- `label` — required trigger `aria-label`
- `size` — `sm` (default) or `md`
- `className` — root `.ds-infotip`

Language-agnostic: apps pass localized strings.
