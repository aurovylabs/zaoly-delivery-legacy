# TokenPreview

Layer: `molecules`

Kind-aware display chip for token paths (color swatch, spacing bar, radius, opacity checker, type “Ag”). Used by `TokenPicker` browser mode and inspect strips.

**Spec:** `specs/domain/zaoly-ui-token-picker.md`

## Usage

```tsx
import { TokenPreview } from '@zaoly/ui'

<TokenPreview kind="radius" value="8px" />
```
