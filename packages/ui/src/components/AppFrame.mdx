# AppFrame

Layer: `Templates`

Shared product shell: atmosphere, optional brand corner, nav rail, topbar, and page body.

## Usage

<Canvas of={Stories.Default} />

## Do

- Compose `NavRail` + `BrandCorner` + page chrome through slots — keep product routes out of the primitive.
- Prefer `railEdge` to mirror dock orientation when the rail is static.

## Don't

- Put domain data fetching or route trees inside AppFrame.
- Nest multiple AppFrames on one page.
