# Avatar

Face mark with image or initials. **Default shape is `square`** (magazine portraits). Use `shape="round"` for dense list/table marks.

## Usage

<Canvas of={Stories.Default} />
<Controls of={Stories.Default} />

## Round (workstation)

<Canvas of={Stories.Round} />

## Do

- Pass `name` for initials and accessible label when no `src`.
- Prefer square for AUDION/CHECKION portrait grids and heroes.

## Don't

- Use round on magazine cover / persona index tiles.
