# BrandCorner

Layer: `Molecules`

Top-right Zaoly cutdown brand lockup for product shells. Default is **logo-only**; the product label expands left on hover/focus.

## Usage

<Canvas of={Stories.Default} />

## Do

- Pass the product name as `label`.
- Slot into `AppFrame` via `brandCorner`.
- Use `labelReveal="always"` only when the full lockup must stay visible.

## Don't

- Rebuild corner geometry per app — use `corners` only for deliberate cutdown overrides.
