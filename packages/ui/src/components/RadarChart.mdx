# RadarChart

Layer: `molecules`

Spider / radar for a small set of 0–1 categorical scores. Spec: `specs/domain/zaoly-ui-radar-chart.md`.

## Props
- `data` — `{ label, value }[]` (values clamped to 0–1)
- `title` / `ariaLabel` — accessible name
- `size` — SVG viewBox edge (default 240)
- `onPointClick` — axis / label activation

## Stories
Default · ManyAxes · Empty · Interactive
