# Chart

Layer: `molecules`

Magazine SVG chart for Collection analytics. Spec: `specs/domain/zaoly-ui-chart.md`.

## Variants

`bar` · `bar_horizontal` · `line` · `area` · `scatter` · `pie` · `donut` · `funnel`

Single-series `ChartPoint[]` only. Interactive clicks via `onPointClick`.

## Accessibility

SVG `role="img"` plus a screen-reader data table (`ds-chart__table`).
